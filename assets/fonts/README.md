# Local web fonts

DM Sans (normal, weights 400–700) and Playfair Display (normal/italic,
weights 400–500) are self-hosted WOFF2 fonts. Their Unicode subsets match
the existing typography; browsers download only the subsets they use.

Sources: the Google Fonts distributions of DM Sans and Playfair Display.
These files are served by this website; visitors do not contact Google.
The original SIL Open Font Licenses are included alongside the font files.

Allura is also self-hosted as WOFF2 subsets here; its license is in
`../Allura-LICENSE.txt`. The original `../Allura-Regular.ttf` is retained
but is no longer downloaded by the page. Animated quote lettering uses
the local EMS Allure paths in `../handwriting-font.js`.
